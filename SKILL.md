# /teach

Делает обучающие видео по проекту: зритель смотрит урок и после него умеет пользоваться функцией сам. Основа взята из `/brag` (план → раскадровка → сборка → проверка кадров → рендер → постер), но цель другая: не похвастаться, а научить.

Видео собирается из реального приложения. Скилл запускает его, проходит сценарий через Playwright и снимает скриншоты состояний вместе с координатами элементов. Плеер (`assets/player.html`) анимирует поверх них курсор, клики, ввод, зум и подсветку, а голос задаёт тайминг всего урока. Голос — Piper (офлайн, стандартные русские голоса) или клонированный голос из локального приложения Voicebox.

`<skill-dir>` — папка этого файла. Скрипты лежат в `<skill-dir>/scripts/`, плеер — в `<skill-dir>/assets/`.

## Вызов

```
/teach                      проанализировать проект и предложить учебный план серии
/teach план                 то же самое, только план, без съёмки
/teach 3                    снять урок №3 из утверждённого плана
/teach "Корзина"            снять урок про конкретную функцию или страницу
/teach все                  снять все уроки плана подряд
```

| Опция (флагом или словами) | По умолчанию |
|---|---|
| `--audience user\|dev` | `user`: как пользоваться. `dev`: как устроено, больше сцен с кодом |
| `--voice dmitri\|irina\|denis\|ruslan\|none` | `dmitri`. `none`: без голоса, только субтитры |
| `--voice voicebox:<профиль>` | клонированный голос из Voicebox, например `voicebox:Диктор`. См. [references/voicebox.md](references/voicebox.md) |
| `--speed <x>` | `1.0`; 1.1 быстрее, 0.9 медленнее |
| `--format landscape\|vertical` | `landscape` 1920×1080 30fps; vertical 1080×1920 для Shorts/Reels |

Результат пишется в `teach-output/` в корне проекта. В claude.ai, где проект загружен архивом, это рабочая папка песочницы, а готовые файлы копируются в `/mnt/user-data/outputs/`.

```
teach-output/
  curriculum.md            учебный план серии (читает человек)
  curriculum.json          тот же план для скрипта
  01-dobavlenie-zadach/
    script.md              сценарий урока: реплики и что на экране
    shots.json             сценарий съёмки в браузере
    episode.json           сцены, реплики, события для плеера
    shots/                 скриншоты + boxes.json
    narration.wav  timeline.json  subtitles.srt
    video.mp4  poster.jpg  description.md
    work/                  стоп-кадры, куски рендера
```

## 0. Окружение

Один раз за сессию:

```bash
npm install --prefix <skill-dir>/scripts
python3 -m pip install piper-tts     # или: uv run --no-project --with piper-tts python ...
node <skill-dir>/scripts/doctor.mjs
```

`doctor.mjs` проверяет node, Chromium, ffmpeg, piper и доступ к голосовой модели и для каждого провала печатает, как его исправить. Пока он не зелёный, дальше не идти, а исправить по подсказке. Если голос недоступен (в claude.ai по умолчанию закрыт huggingface.co), скажи пользователю, что домен `huggingface.co` нужно разрешить в настройках выполнения кода, и предложи снять урок с `--voice none`.

С голосом из Voicebox piper не нужен, вместо него проверяется приложение: `node <skill-dir>/scripts/doctor.mjs --voice "voicebox:<профиль>"`. Voicebox работает только на машине пользователя (Claude Code), в песочнице claude.ai его нет. Перед первым уроком прочитай [references/voicebox.md](references/voicebox.md): там как выбрать и подготовить голос и сколько займёт озвучка.

## 1. Разбор проекта

Прочитай код целиком, а не только README:

- **Карта страниц.** Роуты (`pages/`, `app/`, `routes`, конфиг роутера), вложенные страницы, модалки, вкладки. Для каждой страницы: что пользователь на ней делает.
- **Функции.** Всё, что пользователь может сделать: формы, действия, фильтры, настройки, импорт и экспорт. Для каждой функции: сколько шагов, на каких страницах, от чего зависит (нужен логин? нужны данные?).
- **Айдентика.** Точные цвета, шрифт и логотип из стилей проекта. Акцентный цвет уйдёт в `theme.accent`.
- **Как запустить.** Команды из `package.json` или README, порт, сид-данные, тестовый пользователь из фикстур. Если бэкенда нет или его не поднять, API подменяется фикстурами (`routes` в `shots.json`, данные берутся из моков и типов проекта, а не выдумываются).

Запусти приложение (dev-сервер в фоне) и пройди его глазами: сделай пару скриншотов через `capture.mjs`. План строится на том, что реально работает, а не на том, что написано в README.

## 2. Учебный план серии

**Прочитай:** [references/curriculum.md](references/curriculum.md)

Разбей проект на уроки: один урок — одна цель пользователя. Большая функция получает отдельный урок, а иногда и два. Мелкие функции одной страницы или темы объединяются в один урок. Длина урока следует из содержания, а не из лимита.

Запиши `teach-output/curriculum.md` и `curriculum.json`, покажи план пользователю коротко (номер, название, что внутри, примерная длина) и **дождись подтверждения**, прежде чем снимать. Исключения: план уже утверждён, или пользователь сразу попросил конкретный урок или «все».

## 3. Сценарий урока

**Прочитай:** [references/narration.md](references/narration.md)

Форма урока:

```
Титул (цель урока)  →  Шаги: по сцене на шаг, каждый показан в живом интерфейсе
→ [для dev: код, который это делает]  →  Итоги (чек-лист умений + что дальше)
```

Напиши `script.md`: реплики по сценам и что в этот момент происходит на экране. Каждое действие на экране привязано к слову в реплике: «нажмите **„Добавить“**» звучит ровно тогда, когда курсор кликает.

## 4. Съёмка

**Прочитай:** [references/episode-format.md](references/episode-format.md)

Напиши `shots.json`: шаги в браузере и скриншоты нужных состояний с координатами элементов. Затем запусти:

```bash
node <skill-dir>/scripts/capture.mjs teach-output/NN-slug/shots.json teach-output/NN-slug/shots
```

Если шаг упал, открой `shots/_error.png` и поправь селектор или ожидание. Данные в кадре должны выглядеть правдоподобно и по-русски («Купить молоко», а не «test123»). Пустые экраны допустимы, только если урок как раз о них.

## 5. Эпизод и голос

Напиши `episode.json`: сцены, реплики (`say` — что читает голос, `sub` — что видно в субтитрах), события на экране, привязанные к репликам (`"at": "L1+0.4"`). Затем:

```bash
python3 <skill-dir>/scripts/tts.py teach-output/NN-slug/episode.json teach-output/NN-slug [--voice irina] [--no-voice]
```

Скрипт озвучивает каждую реплику и выкладывает их на общую дорожку. Длина сцен получается из голоса, поэтому задавать секунды вручную не нужно. Послушай одну-две реплики из `lines/`: если ударение или английский термин звучат криво, перепиши `say` (см. narration.md) и запусти скрипт снова.

С `--voice "voicebox:<профиль>"` каждая реплика генерируется в Voicebox и кэшируется в `lines/`: повторный запуск переозвучивает только изменённые реплики, поэтому правь `say` точечно и не бойся перезапускать. На машине без видеокарты озвучка идёт примерно минуту на 10 секунд речи: запускай скрипт в фоне и предупреди пользователя о времени. Проверку реплик делай так же, а если реплика звучит странно (лишние слова, обрыв), смени формулировку или `--seed` всей серии.

### Фоновая музыка (по желанию)

```bash
python3 <skill-dir>/scripts/music.py teach-output/NN-slug [--level -26] [--track свой-трек.mp3] [--seed 7]
```

Скрипт синтезирует тихую мелодию (мягкие аккорды и редкие ноты, без чужих сэмплов и лицензий) длиной в урок или берёт ваш трек и подмешивает его под голос. Во время речи музыка приглушается, в паузах возвращается. Результат — `soundtrack.wav`: `render.mjs` берёт его вместо `narration.wav`, если он не старше голоса. После переозвучки снова запусти `music.py`. Один `--seed` (или один трек) на всю серию.

## 6. Проверка кадров и рендер

```bash
node <skill-dir>/scripts/render.mjs teach-output/NN-slug --stills auto     # кадр из середины каждой сцены и со стыков
node <skill-dir>/scripts/render.mjs teach-output/NN-slug --stills 4.2,9.8  # конкретные моменты
```

**Посмотри стоп-кадры** (`work/stills/`) до полного рендера. Проверь: курсор попадает в цель, подсветка обводит нужный элемент, набранный текст не налезает на плейсхолдер, при зуме цель в кадре, субтитры не перекрывают важное, на стыках сцен нет каши. Добавь кадры на момент каждого клика и зума. Исправь и проверь снова.

```bash
node <skill-dir>/scripts/render.mjs teach-output/NN-slug
```

Рендер идёт кусками по 20 секунд в `work/chunks/`. Если команду оборвал таймаут (в claude.ai у команд есть лимит), запусти её ещё раз: готовые куски не пересчитываются. На выходе получаются `video.mp4` и `poster.jpg`. Кадр 0 — титульная карточка в собранном виде, она же обложка.

## 7. Сдача

- `description.md`: название урока, 1–2 предложения «что вы научитесь делать», **таймкоды** глав (начала сцен из `timeline.json`, формат `0:00 Название`), ссылка на предыдущий и следующий урок серии.
- `subtitles.srt` уже готов, его можно загрузить на YouTube или в VK Видео.
- Если урок озвучен голосом из Voicebox, добавь в `description.md` строку «Озвучка: синтезированный голос (Voicebox)».
- Обнови в `curriculum.md` статус урока (снят, длина).
- Скажи пользователю, где лежат видео, субтитры и описание, одной фразой опиши, как построен урок, и предложи следующий урок по плану или переснять сцену.

## Законы обучающего видео

- **Одна цель на урок.** Название урока — это то, что зритель сможет сделать после него («Добавляем и закрываем задачи»), а не название раздела («Модуль задач»).
- **Сначала зачем, потом как.** Первая реплика говорит, что мы научимся делать и зачем это нужно. Не «в этом видео мы рассмотрим», а «научимся добавлять задачи и отмечать готовые».
- **Показывай настоящее.** Только реальный интерфейс проекта, его реальные подписи и сценарии. Не выдумывай функций, кнопок и цифр, которых нет в коде.
- **Действие совпадает со словом.** Клик звучит в момент клика, подсветка появляется, когда элемент называют. Глаз и ухо не должны спорить.
- **Один шаг — одно действие в фокусе.** Курсор, подсветка или зум ведут взгляд. Одновременно подсвечено не больше одной вещи.
- **Называй элементы так, как они подписаны в интерфейсе**: «нажмите «Сохранить»», а не «нажмите синюю кнопку справа».
- **Темп для понимания.** После действия дай секунду увидеть результат, прежде чем говорить дальше. Зум, когда элемент мелкий. Никакой спешки ради динамики.
- **Субтитры всегда.** Многие смотрят без звука. Субтитр — это та же фраза, что звучит, разве что с правильным написанием терминов.
- **Каждый кадр чистый.** Ничего не обрезано и не перекрыто, текст контрастный. Любой стоп-кадр можно вставить в документацию.
- **Серия — одно целое.** Один голос, один акцентный цвет и одна шапка у всех уроков. Итоги каждого урока анонсируют следующий. Выбранный голос (и `--seed` для Voicebox) запиши в `curriculum.md` и используй для всех уроков.
- **Чужой голос — только с согласия.** Клонируй голос самого пользователя или человека, который на это согласился, и не выдавай синтезированную озвучку за живую запись.
