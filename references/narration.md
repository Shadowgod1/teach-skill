# Озвучка и субтитры

Голос — Piper: офлайн-нейросеть, русские голоса `dmitri` и `denis` (мужские), `irina` (женский), `ruslan` (мужской). Или клонированный голос из Voicebox (`--voice "voicebox:<профиль>"`, см. [voicebox.md](voicebox.md)). Один голос на всю серию. TTS читает буквально, поэтому текст для голоса (`say`) пишется для уха, а текст субтитров (`sub`) — для глаза.

## Как писать реплики

- **Коротко.** Одна реплика — одна мысль, 6–18 слов. Длинное предложение режь на две реплики: каждая реплика — это отдельный субтитр.
- **Обращение на «вы»**, живо и без канцелярита: «Нажмите «Добавить»», а не «Необходимо осуществить нажатие на кнопку».
- **Начало урока — результат:** «Научимся добавлять задачи и отмечать выполненные». Не «Всем привет, в этом видео мы с вами рассмотрим...».
- **Названия из интерфейса в кавычках-ёлочках**, ровно как подписано: «Сохранить», «Готовые».
- **Без слов-паразитов про экран:** «как вы видите», «вот здесь» — лишние, взгляд ведёт курсор.
- **Конец урока:** итог «теперь вы умеете...» и мостик к следующему уроку.
- Ставь **ё**, это помогает правильному произношению: «зачеркнётся».

## Английское и технические термины

Piper читает латиницу плохо. В `say` пиши так, как произносится, в `sub` — как пишется:

```json
{ "say": "Откройте Гитхаб и скопируйте эй-пи-ай ключ.", "sub": "Откройте GitHub и скопируйте API-ключ." }
{ "say": "Компонент таск-лист рендерит список.",       "sub": "Компонент TaskList рендерит список." }
```

Аббревиатуры: «эс-кью-эль», «пэ-дэ-эф», «ю-ар-эл». Числа и даты лучше писать словами, если важен падеж: «до пятнадцатого марта». Имена файлов в `say` не зачитывай, а описывай словами: «в файле с формой».

## Ударения

Если слово звучит с неправильным ударением, замени его синонимом или перестрой фразу. Послушай `lines/<сцена>-<n>.wav` у сомнительных реплик.

## Паузы и темп

- Между репликами по умолчанию 0,35 с, после последней реплики сцены — 0,6 с. Перед первой репликой сцены — 0,5 с (`leadIn`).
- После реплики, за которой следует действие с видимым результатом, поставь `"pause": 1.0`–`1.5`, чтобы зритель успел увидеть результат.
- Если сцена без слов (например, демонстрация длинного ввода), задай ей `minDur`.
- `--speed 1.1` ускоряет голос на всю серию. Скорость не меняют от урока к уроку.

## Без голоса

`--no-voice` (`--voice none`): дорожка тишины, реплики по 0,4 с на слово, остаются только субтитры. Писать реплики нужно точно так же.
