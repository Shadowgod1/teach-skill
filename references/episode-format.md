# Формат урока: shots.json и episode.json

Полный рабочий пример лежит в [example/](example/): демо-приложение «Дела» (`example/app/index.html`), его `shots.json` и `episode.json`. Из них получается 50-секундный урок. Начинай новый урок с копии примера.

## shots.json — что снять

Сценарий для `capture.mjs`: шаги выполняются в реальном браузере сверху вниз.

```json
{
  "baseUrl": "http://localhost:5173",
  "viewport": { "w": 1600, "h": 900 },
  "scale": 2,
  "routes": { "**/api/tasks": { "json": [{ "id": 1, "title": "Купить молоко" }] } },
  "steps": [
    { "goto": "/login" },
    { "fill": ["#email", "demo@example.com"] },
    { "fill": ["#password", "demo-password-from-seed"] },
    { "click": "button[type=submit]" },
    { "waitFor": "text=Мои задачи" },
    { "shot": "home", "boxes": { "title": "#title", "add": "#add", "list": "#list" } },
    { "fill": ["#title", "Купить молоко"] },
    { "shot": "typed", "boxes": { "add": "#add" } },
    { "click": "#add" },
    { "shot": "added", "boxes": { "new": "li >> nth=2" } }
  ]
}
```

Шаги: `goto`, `click`, `fill [sel, text]`, `type [sel, text]` (посимвольно), `press [sel, key]`, `hover`, `select [sel, value]`, `waitFor sel`, `wait ms`, `scroll y|sel`, `eval js`, `drag [from, to]` (+ `at: {x, y}` — точка сброса внутри цели), `routes {…}`, `shot`.

**Фикстуры вместо бэкенда.** `routes` отвечают на запросы приложения заранее заготовленными данными. Если подходят несколько шаблонов, отвечает зарегистрированный последним, поэтому общий `…/api/**` ставят первым, а конкретные после него. Шаг `{ "routes": { … } }` посреди сценария подменяет ответы: после клика «Записать» список приходит уже с новой записью. Привязывай шаблоны к адресу сайта (`http://127.0.0.1:5173/api/**`), а не к `**/api/**`: голый шаблон под Vite перехватит и исходники вроде `/src/api/index.js`, и вместо приложения будет белый экран.

**Вход без логина.** `"localStorage": { "token": "demo", "user": { … } }` кладёт значения до загрузки страницы (не строки сохраняются как JSON). Так SPA с токеном в localStorage открывается сразу на нужном экране, а данные пользователя (роль, права, флаги) берутся из фикстур проекта.

**Даты.** Если интерфейс прокручивается к «сейчас» или не даёт записать в прошлое, снимай урок на завтрашний день: все слоты в будущем, линии текущего времени нет.

`shot` сохраняет `shots/<имя>.png` и координаты элементов из `boxes` (ключ → селектор Playwright) в `shots/boxes.json`. `"fullPage": true` снимает страницу целиком, и плеер может прокручивать её событием `pan`.

**Правило:** снимай каждое состояние, которое зритель должен увидеть: до действия, после ввода, после клика. Плеер не умеет менять интерфейс, он только переключает снятые состояния и рисует поверх них курсор, ввод и подсветку. Бокс снимай в том кадре, где элемент будет целью.

`viewport` — размер окна приложения внутри видео. 1600×900 подходит для десктопных интерфейсов, 1280×720 — если интерфейс мелкий (элементы станут крупнее), 390×844 — для мобильной вёрстки в формате vertical.

## episode.json — что показать и сказать

```json
{
  "series": "Дела — обучение",
  "title": "Добавляем и закрываем задачи",
  "episodeLabel": "Урок 1",
  "url": "dela.app/tasks",
  "format": { "w": 1920, "h": 1080, "fps": 30 },
  "viewport": { "w": 1600, "h": 900 },
  "theme": { "accent": "#ff6b3d" },
  "subtitles": true,
  "scenes": [ ... ]
}
```

`theme` переопределяет CSS-переменные плеера: `accent`, `bg`, `fg`, `muted`, `panel`, `font`, `mono`. Свой шрифт проекта подключается файлом `theme.css` в папке урока (`@font-face` с путём `/fonts/...` относительно папки урока). `url` — что написано в адресной строке окна; у каждой сцены может быть свой `url`.

### Сцены

У каждой сцены есть `id` (уникальный), `type` и `lines` — реплики `{ "say", "sub"?, "pause"? }`. Длина сцены вычисляется из голоса.

**`title`** — титульная карточка. Первая сцена урока, её кадр 0 становится обложкой.
```json
{ "id": "intro", "type": "title", "kicker": "Дела · Урок 1", "title": "Добавляем и закрываем задачи",
  "subtitle": "Полторы минуты — и список дел под контролем.", "goals": ["Новая задача", "Отметка «готово»"],
  "lines": [{ "say": "Научимся добавлять задачи и отмечать выполненные." }] }
```

**`screen`** — окно приложения со снятыми состояниями.
```json
{ "id": "add", "type": "screen", "shot": "home", "step": "Добавляем задачу",
  "lines": [...], "events": [...] }
```
`shot` — начальное состояние. `step` — подпись шага в правом верхнем углу (шаги нумеруются сами: «1 / 3»). Подряд идущие screen-сцены не мигают: окно остаётся, меняется только содержимое. `cursorFrom: [x, y]` задаёт стартовую точку курсора, `hideCursor: true` прячет курсор.

**`code`** — разбор кода (для `--audience dev`).
```json
{ "id": "code", "type": "code", "file": "src/TaskForm.tsx", "lang": "tsx", "firstLine": 12,
  "reveal": "lines", "code": "...реальный фрагмент из проекта...", "lines": [...],
  "events": [{ "do": "focus", "lines": [15, 17], "at": "L1" }] }
```
Код копируется из проекта как есть. Можно вырезать фрагмент до 25–30 строк, но не переписывать. `firstLine` — номер первой строки в файле, номера в `focus` указываются в нумерации файла.

**`recap`** — итоги: пункты появляются по одному вместе с репликами (пункт i — на реплике i+1, первая реплика — вступление; иначе задай `itemsFromLine` или `items[i].at`).
```json
{ "id": "recap", "type": "recap", "kicker": "Итоги урока", "title": "Теперь вы умеете",
  "items": ["Добавлять задачи", "Отмечать их выполненными"],
  "lines": [{ "say": "Итак, теперь вы умеете:" }, { "say": "добавлять задачи," }, { "say": "и отмечать их выполненными." },
            { "say": "В следующем уроке — сроки и напоминания." }] }
```

### Время событий

`at` задаётся относительно начала сцены:
- число — секунды от начала сцены: `1.5`;
- `"L2"` — начало реплики 2 (с нуля), `"L2+0.8"` — через 0,8 с после её начала;
- `"L2e"` — конец реплики 2, `"L2e-0.3"` — за 0,3 с до конца.

Вместо `dur` можно написать `"until": "L3"`: событие длится до этого момента. Привязывай действие к слову: если в реплике «и нажмите «Добавить»» слово «Добавить» звучит примерно на 1 с, ставь клик на `"L2+1.0"`.

### События screen-сцены

| Событие | Что делает | Параметры |
|---|---|---|
| `{"do":"click","on":"add","at":...}` | курсор подлетает к элементу (за `move` = 0,7 с) и кликает в момент `at` | `on`: ключ бокса или `[x,y]`; `move` |
| `{"do":"cursor","to":"title","at":...}` | только переместить курсор | `to`, `move` |
| `{"do":"shot","src":"added","at":...}` | переключить на другое снятое состояние (плавно 0,3 с) | ставь через 0,1–0,2 с после клика |
| `{"do":"type","box":"title","text":"Купить молоко","at":...,"until":"L2"}` | набирает текст в поле по буквам | `typeDur`, `size` (px шрифта приложения), `color`, `bg` (фон поля, по умолчанию белый), `padX`, `font` |
| `{"do":"highlight","box":"new","at":...,"dur":2,"label":"Новая задача"}` | рамка акцентного цвета и подпись | `dim: true` затемняет всё вокруг; `side: "top"\|"bottom"`; `pad` |
| `{"do":"zoom","box":"check","scale":1.9,"at":...,"until":"L1e"}` | камера наезжает на элемент и возвращается | `scale` 1.4–2.2 |
| `{"do":"pan","to":"footer","at":...,"dur":1.2}` | прокрутка длинной страницы (fullPage-кадр) | `to`: число px или ключ бокса; `offset` |

Ключ бокса ищется в состоянии, которое показано в момент события. Чтобы взять бокс из другого кадра, пиши `"shot:key"`: `"added:new"`.

Типичный клик с результатом:
```json
{ "do": "click", "on": "add", "at": "L2+0.9" },
{ "do": "shot", "src": "added", "at": "L2+1.05" },
{ "do": "highlight", "box": "new", "at": "L2+1.4", "dur": 2, "label": "Новая задача" }
```

Типичный ввод: снимок пустого поля → `click` на поле → `type` → `shot` с заполненным полем в момент, когда `type` заканчивается.

Перетаскивание: плеер не двигает элементы, поэтому курсор наводится на карточку (`cursor` → `to: "card"`), медленно едет к точке сброса (`cursor` → `to: [x, y]`, `move` 1–1,5 с), и в этот момент кадр переключается (`shot`) на результат, снятый шагом `drag`.
