# /teach

Скилл для Claude, который превращает проект в серию обучающих видео с русской озвучкой.

Claude читает код, составляет карту страниц и функций и предлагает учебный план серии: большая функция становится отдельным уроком, мелкие объединяются. Затем он запускает приложение, проходит сценарий в настоящем браузере и собирает урок: окно приложения, курсор, клики, ввод текста, зум, подсветка, при необходимости разбор кода, а в конце итоги. Голос синхронизирован с действиями на экране, субтитры идут всегда.

На выходе каждого урока: `video.mp4` (1080p), `poster.jpg`, `subtitles.srt` и `description.md` с таймкодами.

## Установка

**claude.ai:** скачай zip с папкой `teach/` (Code → Download ZIP и оставь в архиве только папку со `SKILL.md`, либо возьми собранный `teach-skill.zip`) и загрузи его в Settings → Capabilities → Skills. Нужно включённое выполнение кода. Чтобы скачалась голосовая модель, добавь `huggingface.co` в разрешённые домены выполнения кода. Без этого уроки снимаются только с субтитрами (`--voice none`).

**Claude Code:**

```bash
git clone https://github.com/Shadowgod1/teach-skill ~/.claude/skills/teach
```

## Использование

```text
/teach                 разобрать проект и предложить учебный план
/teach 2               снять урок №2 из плана
/teach "Корзина"       урок про конкретную функцию
/teach все             снять всю серию
/teach --audience dev  уроки для разработчиков, со сценами кода
```

В claude.ai приложи проект zip-архивом или дай ссылку на публичный репозиторий.

## Как устроено

| Файл | Роль |
|---|---|
| `SKILL.md` | процесс: разбор → план серии → сценарий → съёмка → голос → проверка кадров → рендер |
| `references/` | правила нарезки уроков, формат `episode.json`, правила озвучки, рабочий пример |
| `scripts/capture.mjs` | Playwright проходит сценарий в приложении и снимает состояния и координаты элементов |
| `scripts/tts.py` | озвучка Piper (офлайн; голоса dmitri, irina, denis, ruslan) → `narration.wav`, `timeline.json`, `.srt` |
| `assets/player.html` | плеер, в котором каждый кадр — чистая функция времени |
| `scripts/render.mjs` | покадровый рендер кусками (с продолжением после обрыва) + ffmpeg |
| `scripts/doctor.mjs` | проверка окружения с подсказками, как исправить |
